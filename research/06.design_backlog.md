# Design Backlog: Conversational Memory System

## How to read this
Every idea considered during the weekly research scans is recorded here with its
status and a one-line reason. Statuses are: adopt, prototype, defer, reject.
This is the running audit trail across all weeks, so nothing considered is lost.

## Status legend
- adopt: accepted into the design; an ADR is written
- prototype: promising but unproven; build a small test before deciding
- defer: potentially useful later, not now
- reject: considered and declined, with reason
